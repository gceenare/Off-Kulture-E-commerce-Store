# Off-Kulture-E-commerce-Store
E‑commerce storefront UI and assets (based on Figma design).

About

This repository contains the UI and assets for the Off Kulture E-commerce Store, created from a Figma design.

Features

- Storefront UI components
- Example product pages

Tech Stack

- React / Next.js or static frontend

Quick start

```bash
# clone
git clone https://github.com/gceenare/Off-Kulture-E-commerce-Store.git
cd Off-Kulture-E-commerce-Store
npm install
npm run dev
```
